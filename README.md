# webtiles-sample-plugin

Template for building [WebTiles](https://github.com/micheldore/webtiles) plugins, the equivalent of Obsidian's
[`obsidian-sample-plugin`](https://github.com/obsidianmd/obsidian-sample-plugin). Click **Use this template** to start
a new plugin, then load it in WebTiles through developer mode.

This template is not published to npm.

> **Status:** stub. The template contents are built in
> [micheldore/webtiles#117](https://github.com/micheldore/webtiles/issues/117).

Plugin API docs: [ADR-0001](https://github.com/micheldore/webtiles/blob/main/docs/adr/0001-plugin-architecture.md) and
[`docs/plugins/`](https://github.com/micheldore/webtiles/tree/main/docs/plugins) in the host repo.
